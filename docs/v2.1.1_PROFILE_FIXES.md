## Debug Profile Fixes (f537c67)

### Problem 1: Vulture CLI Invocation Bug
```
vulture app/ --exclude tests --make-whitelist logs/vulture_whitelist.py
→ Exit 2: unrecognized arguments
```

**Root cause:** Argparse requires ALL OPTIONS FIRST, then positional paths.

**Fix:**
```python
# OLD (broken)
cmd = ["vulture", "app/", "--exclude", "X", "--make-whitelist", "logs/"]

# NEW (working)
cmd = ["vulture", "--exclude", "X", "--min-confidence", "60", 
       "--sort-by-size", "app/", "meta/whitelists/vulture_framework.py"]
```

**Changes:**
- Move all `--options` before paths
- Remove non-existent `--make-whitelist` flag
- Move whitelist: `logs/` → `meta/whitelists/`
- Add `--sort-by-size` for better UX

**Impact:** Exit 2 → Exit 0/3, no longer tanks debug/AI bundles

### Problem 2: Radon Scanning Artifacts
```
Duplicate complexity reports from:
- artifacts/pybundle_analysis_20260103T132352Z/src/
- artifacts/pybundle_analysis_20260103T132401Z/src/
- artifacts/pybundle_analysis_20260103T132607Z/src/
```

**Root cause:** Exclude patterns using wildcards (`artifacts/*`) didn't work with radon's CLI.

**Fix:**
```python
# OLD (wildcards didn't work)
cmd = ["radon", "cc", "--exclude", "artifacts/*", "--exclude", ".venv/*"]

# NEW (comma-separated, simple patterns)
exclude = "artifacts,.venv,venv,.freeze-venv,.gaslog-venv,*-venv,*_venv,__pycache__"
cmd = ["radon", "cc", "--exclude", exclude, root]
```

**Changes:**
- Single `--exclude` with comma-separated patterns
- Added custom venv detection: `*-venv`, `*_venv`, `.gaslog-venv`
- Simplified patterns (no wildcards for paths)

**Impact:** No duplicate reports from artifacts

## AI Profile Fixes (99b60dd)

### Problem 1: Env Vars "Basically Your Entire OS"
```
Environment variables detected:
- ANDROID_ROOT
- SSLKEYLOGFILE
- GITHUB_ACTIONS
- PYTEST_CURRENT_TEST
- CC, CXX, CFLAGS
- (entire OS/toolchain env)
```

**Root cause:** `_extract_env_vars()` scanned all .py files without PROJECT filter or OS noise filtering.

**Fix:**

1. **Changed return type:**
   ```python
   # OLD
   def _extract_env_vars(root: Path) -> set[str]
   
   # NEW
   def _extract_env_vars(root: Path) -> dict[str, list[tuple[str, int]]]
   ```

2. **Added OS noise filter (60+ patterns):**
   ```python
   OS_NOISE = {
       "GITHUB_ACTIONS", "PYTEST_*", "ANDROID_*",
       "CC", "CXX", "PYTHONPATH", "VIRTUAL_ENV",
       "SSLKEYLOGFILE", "PATH", "HOME", ...
   }
   ```

3. **Use PROJECT filter:**
   ```python
   for p in root.rglob("*.py"):
       if should_exclude_from_analysis(p):  # Skip venvs/caches
           continue
   ```

4. **Track file:line references:**
   ```python
   env_vars[var_name].append((rel_path, line_num))
   ```

**Updated display in `_generate_configuration()`:**
```markdown
**Required environment variables:**
* `DATABASE_URL` — used in [app/db.py:15, app/config.py:8]
* `SECRET_KEY` — used in [app/auth.py:23]
```

**Impact:**
- Before: OS noise → AI confused
- After: PROJECT env vars only with exact file:line refs

### Problem 2: Entry Points "No entry points detected"
While simultaneously saying:
```
**Run command:** `uvicorn app.main:app --reload`
```

**Root cause:** Generic filename detection, no FastAPI pattern matching, no console script parsing.

**Fix in `_list_entrypoints()`:**

1. **Detect FastAPI apps:**
   ```python
   if "FastAPI(" in content:
       match = re.search(r'(\w+)\s*=\s*FastAPI\(', content)
       rel_path = str(p.relative_to(root)).replace("/", ".")
       entrypoints.append(f"* `uvicorn {rel_path}:{app_var}` (FastAPI)")
   ```

2. **Detect `__main__` blocks:**
   ```python
   if 'if __name__ == "__main__"' in content:
       entrypoints.append(f"* `python {rel_path}` (__main__ block)")
   ```

3. **Parse console scripts:**
   ```python
   scripts = data.get("project", {}).get("scripts", {})
   for name, target in scripts.items():
       entrypoints.append(f"* `{name}` → `{target}` (console script)")
   ```

**Fix in `_detect_run_command()`:**
- Scan actual code for `FastAPI()` patterns
- Build accurate `uvicorn` command from detected app variable

**Impact:**
- Before: "No entry points detected" + contradictory run command
- After: Detects FastAPI apps and shows correct `uvicorn` command

### Problem 3: No Trust Markers

**Fix in `_generate_header()`:**

Added guidance section:
```markdown
**How to interpret this document:**

* **Known Facts** — Extracted directly from code/configs with file:line refs (high confidence)
* **Inferred** — Pattern matching auto-detection (verify before trusting)

When you see file paths or specific references, treat as known fact. 
When you see "(detected)" without refs, verify first.
```

**Impact:** AI assistants can distinguish facts from inferences
